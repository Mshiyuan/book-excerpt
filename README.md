# 书摘

作者：时鸢

在聊天界面对消息划线、写想法，并将摘录与想法导出为图片卡片；支持把不连续的划线合并成一条书摘。
所有数据（设置、笔记本）存于浏览器本地 localStorage，不上传任何服务器。

## 安装

SillyTavern → 扩展（Extensions）→ 安装扩展（Install Extension），粘贴本仓库地址：

```
https://github.com/Mshiyuan/book-excerpt
```

## v1.5.0

### 新功能

#### 两点选线
长文本在手机上不好一次选准时使用：
1. 选中开头几个字，点浮动栏的「设为开头」；
2. 选中结尾几个字，点「设为结尾」；
3. 中间的内容会全部选中，接着划线、写想法或做书摘即可。

默认开启，不需要可在「设置 → 划线」关闭。

#### 卡片正文二次标注
生成书摘卡片后，在卡片正文里选中文字，可以加下划线、荧光笔、改字色或加粗。点已标注的文字可以修改或删除。标注只对本次卡片有效，不会保存到笔记。

#### 编辑正文
单条书摘卡片点「编辑正文」即可手动修改文字。

#### 模板图片直接替换
自定义模板里用到的图片，在卡片预览上点对应位置就能换成自己的图，可随时恢复原图。头像在任何模板里都可以点击更换。

#### 模板管理
- 默认模板和导入的模板放在同一个列表里，可以拖动排序、收藏（收藏的排最前）、隐藏（默认模板也能隐藏）、预览、导出和删除。
- 点列表里的模板即可切换。
- 新增「批量导入」，可以一次选多个 .json / .css 模板文件。

#### 出处按角色 / 按聊天保存
「设置 → 书摘卡片 → 出处保存方式」可选：
- **共用一份**：和旧版一样，所有角色共用（默认）；
- **每个角色**：每个角色各存一套用户名、作者、书名、章名；
- **每个聊天**：每个聊天存档各存一套。

#### 合并：两者都要
合并划线时可以同时存为笔记并生成书摘卡片。

#### 跟随酒馆主题
划线相关的浮动栏会使用酒馆下拉框的样式（包括美化主题）。默认开启。

#### 开发者模式（给模板作者）
在「设置 → 通用 → 高级」开启后，可以直接编辑导入模板的 CSS 并实时预览，还有类名查询器，点卡片上的元素即可查看类名。

#### 其他
- 保存清晰度可选 2x / 3x / 4x / 5x，默认 3x。
- 默认配色也可以隐藏；插件主题色和下划线颜色分开设置。
- 模板、字体、配色可以打包导出和批量导入（「设置 → 通用 → 数据」）。
- 设置面板重新分为「书摘卡片 / 划线 / 通用」三页。

### 修复
- 状态栏（包括酒馆助手渲染的状态栏）里选中文字后不弹出划线浮动栏。
- 上传的图片变糊；上传多张大图时保存失败。
- 模板原本用了图片链接时，换图后预览不变、下载出来却是新图。
- 字距等排版设置在预览和下载出来的图片中不一致。
- 在一个角色的聊天里合并另一个角色的划线时，笔记被存到错误的角色下。

### 升级说明
- 升级后两点选线、跟随酒馆主题、开发者模式默认开启，可在设置中关闭。
- 旧版上传的图片会自动迁移，无需操作。
- 「自由排版」本版本暂不开放。

### 已知问题
- 导出的图片中，括号、引号偶尔会贴近前一个字。

## 基础操作

**划线**
选中文字后浮动栏弹出，点击「划线」。样式可选下划线 / 波浪线 / 荧光笔，颜色可选当前色系的 5 色推荐或自定义色环，支持跨段落选区。

**想法**
浮动栏点击「写想法」。一条划线可挂多条想法；仅写想法不画线时显示为虚线，与正式划线区分。

**改样式**
点击已有划线，弹出工具栏，即时切换样式 / 颜色，或执行 复制 / 删除 / 加想法 / 查看想法 / 做书摘 / 加入合并。

**划线合并**
设置里开启「划线合并」后，点已有划线的工具栏上会多一个「加入合并」；勾好几条后通过悬浮篮子或笔记本的「完成」触发合并，选择存为笔记本条目还是直接生成书摘卡片，也可以选择是否删除原来的散乱划线。合并出的书摘正文可直接点击修改。

**划线持久化**
通过事件订阅 + MutationObserver 双重还原，刷新页面后自动恢复。

## 书摘卡片

入口：浮动栏「书摘」按钮 / 想法编辑器「做成书摘」 / 笔记卡片分享图标 / 想法列表抽屉分享图标。

- **排版**（8 套）：经典、人像、横幅、磁带、影帧、诗笺、锦书、日历
- **颜色**：17 个预设 + 自定义（按背景明度自动配深/浅字色，可单独指定字色）
- **字体**（6 种）：思源宋体、京华老宋体、霞鹜文楷、仓耳今楷、思源黑体、平方韶华
- **排版微调**：正文字号、行距、字距、整体宽度均可调
- **出处**：用户名 / 作者 / 书名 / 章名，均可在「编辑出处」自定义
- **头像**：用户头像 / 角色头像 / 自定义上传
- **水印**：默认显示 SillyTavern，可自定义文字或关闭
- **正文打码**：分享时一键隐去角色名 / 用户名，形式可选涂黑 / 符号 / 自定义符号
- **保留原文删除线**：书摘卡片可保留被划掉文字的删除线效果
- **保存方式**：下载文件 / 弹图长按（内嵌浏览器下载没反应时的自救方式），下载失败自动改用弹图

## 划线色系

工具栏与笔记筛选中的 5 个推荐颜色由色系决定：莫兰迪、马卡龙（默认）、蒙德里安、孟菲斯、马蒂斯。非推荐色可通过工具栏的彩虹按钮调出系统色环选择。

## 自定义模板

入口：设置 - 书摘卡片 - 模板 - 「导入」/「批量导入」，支持 `.json`（`{ "name": "模板名", "css": "...CSS..." }`，或多个模板的数组 / 打包文件）、`.css` 或直接粘贴 CSS 文本。CSS 选择器使用 `.be-card.be-custom`，开启开发者模式后可用类名查询器查看类名。每个自定义模板支持导出为 JSON 分享和删除。

## 笔记本

入口：SillyTavern 扩展菜单 - 书摘笔记。按角色聚合展示划线与想法，支持搜索、筛选（类型 / 划线样式 / 颜色）、想法列表查看，以及划线合并的勾选批量操作。

## 数据

设置 - 数据：导出全部（JSON） / 导入（合并 JSON） / 清空。

存储位置：浏览器 localStorage
- `book-excerpt:settings` 设置项
- `book-excerpt:notes` 笔记数据（按角色索引）
- IndexedDB `book-excerpt-images`：上传的头像与模板图片

## 实现细节

- 截图库：html2canvas 1.4.1，随仓库分发在 `lib/` 目录，加载时本地文件优先，4 个 CDN 镜像（staticfile / bootcdn / jsdelivr / unpkg）作为兜底
- 卡片渲染：clone 到隔离 iframe 后再截图，避免扫描主文档样式表；头像预处理为高分辨率方形 PNG
- 导出倍率按「保存清晰度」2x~5x，canvas 用后释放，避免移动端 OOM
- 自由排版依赖 interact.js 1.10.27（拖拽/缩放/吸附）与 Cropper.js 1.6.2（图片裁剪），同样随仓库分发在 `lib/` 目录本地加载；三个第三方库的版权声明见 [THIRD-PARTY-NOTICES.md](./THIRD-PARTY-NOTICES.md)
